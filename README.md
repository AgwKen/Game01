# 森の中でサッカー

---

## ゲーム概要
本作品は、制限時間60秒以内にできるだけ多くゴールを決める  
サッカーアクションゲームです。  

ゲーム開始前は自由にシュート練習が可能で、  
スペースキーを押すことで本番のチャレンジが開始されます。  

ゴール数がスコアに大きく影響しますが、  
コインを集めることでスコア倍率が上昇し、  
より高得点を狙うことができます。  

最終スコアに応じて、ランキング上位10名に入ると  
名前を登録することができます。  

---

## ゲーム実行方法
1. 「Game_実行ファイル」フォルダを開いてください  
2. `GameSample01.exe` をダブルクリックして起動してください  

---

## 操作説明

※本ゲームはゲームコントローラーでのプレイを強く推奨します。  

### ■ ゲーム開始
- キーボード：`Space`キー  
- ゲームパッド：`START`ボタン  

### ■ 移動（ドリブル）
- キーボード：`W / A / S / D`  
- ゲームパッド：左スティック  

### ■ エイム（方向調整）
- キーボード：矢印キー  
- ゲームパッド：右スティック  

### ■ シュート
- キーボード：`J`キー（長押しでパワー調整）  
- ゲームパッド：`R2`トリガー（長押しでパワー調整）  

※長く押すほど強力なシュートになります。  

### ■ 空中カーブ操作（シュート後）
- キーボード：`W / A / S / D`  
- ゲームパッド：左スティック  

※ボールが空中にある間のみ操作可能です。  

### ■ リセット（やり直し）
- キーボード：`Enter`キー  
- ゲームパッド：`B`ボタン  

---

## カメラ機能

### ■ フリーカメラ切り替え
- キーボード：`F1`キー  

フィールド全体を自由に見渡すことができます。  

### ■ フリーカメラ操作
- 移動：`W / A / S / D`  
- 高さ調整：`Q / E`  
- 視野角（FOV）調整：`Z / X`  

---

## 攻略のポイント
- ゴールの得点が最も重要です  
- コインはスコア倍率を上げるため、余裕があれば回収してください  
- エイムをしっかり合わせることで安定して得点できます
