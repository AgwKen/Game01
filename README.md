# アクションゲーム（ポートフォリオ）

## 概要

本作品は、C++ と DirectX を使用して開発した **アクションゲームのポートフォリオ作品** です。
キーボードおよびコントローラーの両方に対応しており、ゲームプレイおよびデバッグ機能の実装を行っています。

現在は開発途中のため、一部の機能は未完成、またはデバッグ用途としてのみ実装されています。

## 開発環境

* OS：Windows 10 / 11
* 開発言語：C++
* グラフィックス API：DirectX
* 開発環境：Visual Studio

## ビルド・実行方法

1. ソリューションファイル（`.sln`）を Visual Studio で開く
2. 構成を **Debug** に設定
3. ビルド後、実行

※ 現在は Debug ビルドのみ対応しています。

## 実装済み要素

* プレイヤー移動処理（キーボード / コントローラー対応）
* 攻撃アクション
* 魔法（発射処理は未完成）
* デバッグ用フリーカメラ

## 操作方法

### キーボード操作（ゲームプレイ）

* **W / A / S / D**：移動
* **P**：攻撃
* **J**：ファイアボール発射（未完成）
* **Space**：ジャンプ（最終版では未使用予定）

### コントローラー操作

* **左スティック**：移動
* **X ボタン**：攻撃
* **R1 ボタン**：射撃

### デバッグカメラ操作

* **F1**：デバッグ用フリーカメラ ON / OFF
* **W / A / S / D**：カメラ移動
* **方向キー**：カメラ回転
* **Q / E**：高さ調整
* **X / Z**：FOV（視野角）調整

## 補足

本作品は、ゲームプログラミングにおける基礎設計、入力処理、デバッグ機能の実装力を示すことを目的としたポートフォリオです。

今後、機能の完成および調整を行う予定です。
