# サッカーゲーム（ポートフォリオ）

## 概要

本作品は、C++ と DirectX を使用して開発した **サッカーゲームのポートフォリオ作品** です。  
プレイヤーは森のフィールドでボールを蹴り、ゴールを狙いながらコインを集めてスコアを伸ばします。  
コインやゴールによってスコアが増え、最終的に **ランキング（Leaderboard）で他プレイヤーの記録に挑戦すること** が目的のゲームです。

本ゲームは **キーボードおよびゲームパッドの両方に対応** しています。

また、DirectX を使用したリアルタイム描画として、**シャドウマッピング** や **カスタム物理処理** などの実装も行っています。

---

## 開発環境

- OS：Windows 10 / 11  
- 開発言語：C++  
- グラフィックス API：DirectX 11  
- 開発環境：Visual Studio  

---

## ビルド・実行方法

1. ソリューションファイル（`.sln`）を Visual Studio で開く  
2. 構成を **Debug** に設定  
3. ビルド後、実行  

※ 現在は Debug ビルドのみ対応しています。

---

## 実装済み要素

- サッカーボールのキック操作  
- コイン収集システム  
- スコア計算およびランキング（Leaderboard）  
- キーボード / ゲームパッド入力対応  
- カスタムボール物理処理（重力・スピン・バウンド）  
- 壁とのカスタム衝突判定  
- 数学計算によるカスタム地形生成  
- シャドウマッピング（Shadow Mapping）によるリアルタイム影描画  

---

## 操作方法

### キーボード操作

- **W / A / S / D**：プレイヤー移動  
- **マウス**：視点操作  
- **左クリック**：ボールをキック  
- **R**：ボールリセット  

### ゲームパッド操作

- **左スティック**：プレイヤー移動  
- **右スティック**：カメラ操作  
- **RT / R2**：ボールをキック  
- **Y / Triangle**：ボールリセット  

---

## 技術的ポイント

本作品では以下のゲームプログラミング技術を実装しています。

- DirectX11 を使用したリアルタイムレンダリング
- Shadow Map を利用した影描画
- カスタム物理計算によるボール挙動
- 数学計算による地形生成
- 独自の衝突判定システム
- スコア・ランキングシステム

---

## 補足

本作品は、**DirectX を用いたゲームプログラミング能力のポートフォリオ**として制作しています。  
ゲームエンジンを使用せず、グラフィックス処理や物理処理などを **自作で実装すること** を目的としています。
